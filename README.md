# 🚀 FairFlow

Интеллектуальная система распределения заявок с динамическим конструктором правил, учётом весов (сложности) и квалификации исполнителей, а также интеграцией с внешней АИС.

---

## 🏗 Архитектура и стек проекта
* **Backend:** FastAPI (Python), Uvicorn, Pydantic, HTTPX.
* **Frontend / Dashboard:** Tailwind CSS, Chart.js (интерактивные графики в реальном времени).
* **Интеграция:** Асинхронные вебхуки и эмулятор внешней АИС (`ais_mock.py`).

---

## 🌟 Ключевые особенности и реализация требований кейса

1. **Динамический конструктор параметров и правил (Rule Engine):**
   * Позволяет добавлять новые параметры как для заявок (`order.*`), так и для исполнителей (`user.*`) прямо через веб-интерфейс без правки исходного кода.
   * Поддерживает логику сравнения (`==`, `!=`, `>`, `<`, `>=`, `<=`, `in`).

2. **Справедливая математическая модель балансировки (Scoring):**
   * Учитывает сложность/трудоёмкость заявки ($W_{\text{order}}$) и пропускную способность специалиста ($\text{Capacity}$).
   * Использует формулу минимизации удельной нагрузки:
     $$\text{Score}(u) = \frac{\text{CurrentLoad}(u) + W_{\text{order}}}{\max(\text{Capacity}(u), 0.1)}$$
   * Гарантирует точность распределения в пределах целевой погрешности $\pm 1\text{--}2\%$ за счёт суточных лимитов и векторного тай-брейкинга.

3. **Интеграция с внешней АИС:**
   * Эмулятор АИС (`ais_mock.py`) хранит реальные данные и имитирует задержку фиксации в финальной БД (2–5 секунд).
   * Поддерживает полную синхронизацию кэша и дельта-обновления по вебхукам.
   * Автоматический асинхронный колбэк в АИС с ID назначенного исполнителя и заявки после завершения расчёта.

4. **Интерактивные дашборды и отчётность:**
   * Графики фактической загрузки и распределения слотов на базе **Chart.js**.
   * Мониторинг KPI в реальном времени (всего распределено, активные специалисты, погрешность балансировки, средний вес потока).
   * Экспорт аналитики и истории распределений в **Excel / CSV** с поддержкой кодировки UTF-8 BOM.

## ⚙️ Инструкция по запуску

### Шаг 1. Запуск FairFlow(main)

Запустите файл main.py
После загрузки перейдите по адресу: http://127.0.0.1:8000/app

### Шаг 2. Запуск эмулятора внешней АИС
Во втором терминале запустите сервер АИС (порт `8001`):

```powershell
python ais_mock.py
